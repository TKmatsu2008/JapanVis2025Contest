# JapanVis2025Contest Tokyo Metro Network Visualization

## 概要
本プロジェクトでは、**東京の地下鉄（東京メトロ・都営4路線）の移動リズム**を、D3.jsを用いてインタラクティブなネットワーク図として可視化することを目的とする。

- 開発言語・技術: **D3.js**
- データ形式: **JSON**
- 対象時間帯（初期ステップ）: **平日全時間帯**
- 将来的には対象路線や曜日の拡張も予定

## 可視化の対象

- **移動時間**
- **運行頻度**
- **利用者数（乗降者数）**

これらの要素を、駅をノード、駅間移動をエッジとした**ネットワークグラフ**で表現

## データ取得について

### 使用API
- [交通オープンデータセンター（東京メトロAPI）](https://developer.odpt.org/)

### データ取得〜整形の手順
1. **JSON形式でAPIから取得**
2. 必要情報を抽出・加工
3. 以下のノード／エッジ仕様に沿ってJSONで出力

## データ仕様
本プロジェクトでは、以下の2つのJSONファイルを使用
- ノードデータ：Node_metro.json
- エッジデータ：Edge_metro_toei_fulltime.json

### ノード情報（駅）
- 駅名（例: 上野）
- 路線コードリスト（例: ["G", "H"]）
- 路線名リスト（例: ["銀座線", "日比谷線"]）
- 緯度
- 経度
- 1日の平均乗降者数（最新年度）

### エッジ情報（駅間）
- 駅A（始点）
- 駅B（終点）
- 路線名（例: 千代田線）
- 路線カラー（例: #009944）
- 平均移動時間（例: 3分）
- 頻度（24時間の本数）
- 時間帯別頻度（例: [..."05": 8, "06": 14, "07": 24, ...])
- 時間帯別移動時間（例: [..."03": null, "04": 3.2, "05": 3.4, ...])
- 出発時刻リスト（例: ["08:02", "08:10", ...]）

※エッジは**ローカル電車のみ**（快速や特急を除外）  
※**上り・下りの区別可能**
※出発時刻リストはファイル容量の問題で除外
※時間帯別移動時間で該当データがなければnull

## データ取得に関する所感・補足

- 出発時刻リストは、今後何らかの可視化に役立つ可能性あり
- JRなど他路線の拡張も容易
- 時間帯ごとの取得も容易
- 曜日別（平日／土日／祝日）での分類・取得も容易
- 快速や特急の処理には少し工夫が必要
- 一部路線（例：丸ノ内線含む3路線ほど）では**最新のダイヤではない**
    - エッジデータのメタデータで更新日時を確認可能
- 頻度は上下線別に取得しているが、合計値として扱うことも可能
