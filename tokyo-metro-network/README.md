
# 🗾 東京メトロ ネットワーク可視化プロジェクト

このプロジェクトは、東京メトロの駅ネットワークをインタラクティブに可視化するWebアプリケーションです。D3.jsを用いて、駅ノード・路線エッジを地理的に正確な配置で表示し、主要駅のラベルや地図背景との連携も可能です。

## 🎯 目的

- 東京メトロの交通ネットワークを **視覚的に理解** できるようにする
- 観察者が「主要駅の重要性」や「路線の接続構造」を把握しやすくする
- 地理情報（緯度・経度）ベースのレイアウトで直感的な観察を実現

## 🔧 使用技術

- **HTML/CSS/JavaScript**
- **[D3.js v7](https://d3js.org/)**
- **GeoJSON** による地理データ
- ローカルサーバでの静的ファイル配信（推奨：`Live Server` or `Python HTTP server`）

## 📁 フォルダ構成

```
tokyo-metro-network/
├── index.html                 # メインHTML
├── css/
│   └── style.css              # スタイルシート（ノード、ラベルなど）
├── js/
│   └── main.js                # D3.js 本体（地図＋ネットワーク描画）
├── data/
│   ├── Node_metro.json        # 駅ノードデータ（緯度・経度・乗降者数など）
│   └── Edge_metro.json        # 路線エッジデータ（駅間・色・頻度など）
```

## 🚀 実行方法（ローカル）

1. 本リポジトリをクローン／ダウンロード：
   ```bash
   git clone https://github.com/yourname/tokyo-metro-network.git
   cd tokyo-metro-network
   ```

2. 任意の方法でローカルサーバーを起動：

   - Pythonを使う場合：
     ```bash
     python3 -m http.server 8080
     ```

   - または VS Code の拡張機能「Live Server」を使用

3. ブラウザで開く：
   ```
   http://localhost:8080
   ```

## 🖱 主な機能

- ✅ 地理的に正確な駅・路線の描画
- ✅ 路線ごとの色付きエッジ＋アニメーション表示
- ✅ 駅ノードは乗降者数に応じてサイズ調整
- ✅ 主要駅（上位20）のラベル表示
- ✅ 背景地図のオンオフ切替（localStorageで記憶）
